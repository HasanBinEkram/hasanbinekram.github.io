## Publish to GitHub Pages
1. Open your **HasanBinEkram/hasanbinekram.github.io** repository.
2. Upload **the contents of this folder** to the root of the repository (not the outer folder or ZIP file).
3. Commit the changes.
4. Under **Settings → Pages**, select **Deploy from a branch**, `main`, `/(root)`, and save.
5. Wait for deployment, then visit https://hasanbinekram.github.io/.
