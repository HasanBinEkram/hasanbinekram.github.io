# Hasan Bin Ekram — Portfolio Website

A responsive static portfolio built with HTML, CSS and vanilla JavaScript. No installation, npm or build step required.

## Publish using GitHub Pages

1. Create a **public** GitHub repository named `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your exact GitHub username). If you already have that repository, use it.
2. Upload **the contents** of this folder (`index.html`, `style.css`, `script.js`, `assets/`, etc.) into the repository's **root** (not a nested folder). Commit the changes.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
5. Visit `https://YOUR-USERNAME.github.io/` after GitHub finishes deployment.

Alternatively, use any public repository name and your URL will be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Customize

- Edit text, work experience, and contact details in `index.html`.
- Edit theme and layout in `style.css`.
- Replace `assets/hasan-profile.png` to update your portrait.
- Replace `assets/Hasan_Bin_Ekram_CV.pdf` to update the downloadable CV.
- GitHub link is not shown because the account username was not supplied. Add it once known.

## Privacy

This is a **public** portfolio. The website and attached CV contain an email address and phone number. Remove those details if you don't want them publicly accessible.
